# ⚽ LaBOLA 個サル空き枠モニター

LaBOLA（`yoyaku.labola.jp`）の個人フットサル（個サル）の予約状況を定期監視し、**空き枠が残り〇人以下になったタイミング**で **メール** または **LINE** に通知するアプリです。

初期設定として **VIVAIOフットサルパーク豊富（`https://yoyaku.labola.jp/r/shop/3050/`）の土日祝日・朝6:00〜の個サル** が登録されています。管理画面から他の施設や時間帯も自由に増やせます。

## 起動方法

```bash
npm start
```

起動後、ブラウザで `http://localhost:3456` を開いてください。

## ワンショット実行（定期実行・テスト用）

```bash
# 実際にチェック＆通知（WindowsタスクスケジューラやGitHub Actions向け）
npm run check

# 通知を送らずに取得・フィルタ結果だけ確認
npm run check -- --dry-run
```

## 通知の設定手順

管理画面の「🔔 スマホ通知設定」から設定し、「テスト送信」ボタンで動作確認できます。

### 1. メール通知（Gmailの場合）
1. Googleアカウントの「セキュリティ」から **2段階認証プロセス** をオンにします。
2. 同じセキュリティ画面で **「アプリパスワード」** を検索し、新しいアプリパスワード（16桁）を発行します。
3. 管理画面のメール設定に以下を入力して保存します。
   - **SMTPホスト**: `smtp.gmail.com`
   - **ポート**: `587`
   - **送信元メールアドレス**: ご自身のGmailアドレス
   - **アプリパスワード**: 発行した16桁のパスワード
   - **通知先メールアドレス**: 通知を受け取りたいアドレス

### 2. LINE通知（LINE Messaging API）
※LINE Notifyはサービス終了しているため、公式の **LINE Messaging API**（無料プラン：月200通まで）を使用します。
1. [LINE Developers](https://developers.line.biz/) にログインし、プロバイダーと **Messaging APIチャネル** を作成します。
2. 作成した公式アカウントを自分のLINEで友だち追加します。
3. チャネルの **「Messaging API設定」** タブから **チャネルアクセストークン（長期）** を発行します。
4. **「チャネル基本設定」** タブの一番下にある **「あなたのユーザーID」**（`U`から始まる文字列）をコピーします。
5. 管理画面のLINE設定にトークンとユーザーIDを入力し、「有効」にして保存します。

## 他の施設・時間帯への拡張

管理画面の **「＋ 施設・時間帯を追加」** から、任意のLaBOLA施設URL（例：`https://yoyaku.labola.jp/r/shop/xxxx/`）と曜日（土日祝・平日・個別曜日）・開始時刻・通知しきい値を追加できます。日本の祝日（振替休日・国民の休日含む）にも自動対応しています。
